A one-line pickup line spoken by a vending machine to a passing human —
machine-world charm (coil, lights, exact change), one breath, punch at the end.

## Run

```sh
python3 main.py
```

This writes the single-line entry to `/output/entry.txt` (UTF-8, no trailing
newline). The output directory falls back through `$MAKEFUN_OUTPUT_DIR`,
`/output`, `output/` in this repo, then a temp directory.
